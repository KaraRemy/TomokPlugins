# Changelog

All notable changes to this project will be documented in this file.

## [0.0.0.5] - 2026-09-16

### Changed
- **Window Collapse Support**: Removed `ImGuiWindowFlags.NoCollapse` from the Configuration window to enable native title bar collapse buttons.

---

## [0.0.0.3] - 2026-06-27

### Added
- **Support & Community Links**: Added an in-game "Support on Ko-fi" button and Support Discord button directly inside the Help tab of the configuration window.

---

## [0.0.0.2] - 2026-06-12

### Added
- **Family Feud Hosting Suite**: Complete question database, team score management, and multi-template chat output integration.
